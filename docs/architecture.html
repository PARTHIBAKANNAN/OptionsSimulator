📊 Market Microstructure & Cumulative Volume Delta (CVD)

Mathematical formulation of tick-level signed volume delta and indicator calculation algorithms.

Tick-Level Signed Volume Delta (CVD)

Each price tick calculates directional volume contribution by comparing the current tick price $P_t$ against the previous tick price $P_{t-1}$:

ΔV_t = +Vol_t if P_t > P_{t-1}
ΔV_t = -Vol_t if P_t < P_{t-1}
ΔV_t = 0.0 if P_t == P_{t-1}

CVD is accumulated across each 5-minute bar to measure institutional order flow dominance and confirm breakout validity.

Volatility Regime Ratio Formulation

Computes normalized volatility regime by comparing current 1-hour Average True Range (ATR) against its 20-period baseline average:

Vol_Ratio = ATR_14(1H) / SMA_20(ATR_14(1H))

• Ratio > 1.20: High Volatility (Wide Swings)
• 0.80 ≤ Ratio ≤ 1.20: Normal Trend Continuation
• Ratio < 0.80: Compression / Scalping Regime
