08:50:15 IST 2

AI Catalyst Synthesis

Concurrently fetches live quotes for Nasdaq (26,180.46), Brent Crude ($93.87), GIFT Nifty (24,329.00) and scrapes multi-newspaper RSS feeds into Gemini 3.6 Flash. Alerts Telegram.

09:15:00 IST 3

WebSocket Stream Connect

Binary WebSocket feed opens. `DataManager` computes signed volume delta per tick, forms 1M/5M candles, and updates EMA 20/50, RSI, MACD, and CVD delta in real time.

09:25:00+ IST 4

Quantitative Strategy Scan

Scans all 21 strategies. When breakout/bounce conditions are met, it resolves the exact In-The-Money (ITM) strike symbol (e.g. `NSE:NIFTY2682824200CE`) and checks cooldown limits.

Sub-5ms 5

Execution & Pre-Trade Risk

`PaperTrader` verifies the ₹5,000 max daily loss limit, 5-position concurrency limit, and drawdown circuit breaker before filling the trade at live ask/bid with realistic slippage.

15:20:00 IST 6

Stepped TSL & Mandatory Square-Off

Dynamically ratchets stop loss (+20pt, +40pt, +60pt locks). All open intraday positions are automatically squared off by 15:20 IST to eliminate overnight gap risk.

PostgreSQL Database Schema & REST Endpoints

Database tables for position management, trade audits, and complete REST OpenAPI definitions.

PostgreSQL DDL: options_trades

CREATE TABLE options_trades (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    strategy_name VARCHAR(64) NOT NULL,
    symbol VARCHAR(32) NOT NULL,
    underlying VARCHAR(16) DEFAULT 'NIFTY',
    side VARCHAR(8) NOT NULL,
    entry_price NUMERIC(10, 2) NOT NULL,
    exit_price NUMERIC(10, 2) NOT NULL,
    qty INTEGER NOT NULL,
    gross_pnl NUMERIC(12, 2) NOT NULL,
    brokerage NUMERIC(8, 2) DEFAULT 40.00,
    stt NUMERIC(8, 2) NOT NULL,
    exchange_charges NUMERIC(8, 2) NOT NULL,
    gst NUMERIC(8, 2) NOT NULL,
    stamp_duty NUMERIC(8, 2) NOT NULL,
    total_charges NUMERIC(8, 2) NOT NULL,
    net_pnl NUMERIC(12, 2) NOT NULL,
    entry_time TIMESTAMPTZ NOT NULL,
    exit_time TIMESTAMPTZ NOT NULL,
    exit_reason VARCHAR(32) NOT NULL
);
