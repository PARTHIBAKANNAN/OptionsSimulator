OPTION 2: PYTHON SCRIPT (Automatic - 10 mins) ⭐ RECOMMENDED
================================================================================

Step 1: Create file called "download_nifty_data.py" with this code:

---
import pandas as pd
from datetime import datetime, timedelta
import os
from dotenv import load_dotenv
from fyers_apiv3 import fyersModel

load_dotenv()

app_id = os.getenv("FYERS_APP_ID")
app_secret = os.getenv("FYERS_APP_SECRET")
access_token = os.getenv("FYERS_ACCESS_TOKEN")

fyers = fyersModel.FyersClient()
fyers.app_id = app_id
fyers.app_secret = app_secret
fyers.access_token = access_token

end_date = datetime.now()
start_date = end_date - timedelta(days=90)

data = {
    "symbol": "NSE:NIFTY50-INDEX",
    "resolution": "1",
    "date_format": "1",
    "range_from": int(start_date.timestamp()),
    "range_to": int(end_date.timestamp()),
    "cont_flag": "1"
}

print("🔄 Downloading NIFTY data...")
response = fyers.history(data)

if response.get("status") == "ok":
    candles = response["candles"]
    df = pd.DataFrame(candles, columns=["Timestamp", "Open", "High", "Low", "Close", "Volume"])
    df["Timestamp"] = pd.to_datetime(df["Timestamp"], unit='s')
    df["Timestamp"] = df["Timestamp"].dt.strftime("%Y-%m-%d %H:%M:%S")
    df = df[["Timestamp", "Open", "High", "Low", "Close", "Volume"]]
    
    os.makedirs("data/historical", exist_ok=True)
    df.to_csv("data/historical/nifty_90days.csv", index=False)
    print(f"✅ Saved! Rows: {len(df)}")
else:
    print(f"❌ Error: {response}")
---

================================================================================
REQUIRED FILE FORMAT
================================================================================

✅ CORRECT FORMAT:

Timestamp,Open,High,Low,Close,Volume
2026-05-06 09:15:00,24100.00,24150.50,24090.00,24120.00,150000
2026-05-06 09:16:00,24120.00,24180.00,24115.00,24170.00,180000
2026-05-06 09:17:00,24170.00,24200.00,24160.00,24195.00,165000

❌ WRONG FORMAT:

Timestamp | Open | High | Low | Close | Volume  (pipes instead of commas)
2026-05-06T09:15:00Z (wrong timestamp format)
24100 | 24150 | 24090 | 24120  (missing columns)

✅ WHAT TO CHECK:

1. Column order: Timestamp, Open, High, Low, Close, Volume
2. Separator: Commas (,) not pipes (|) or tabs
3. Timestamp format: YYYY-MM-DD HH:MM:SS
4. Rows: Should be ~35,000-36,000 rows
5. Time range: 09:15 to 15:30 IST daily
6. No missing data: No blank cells or zeros
