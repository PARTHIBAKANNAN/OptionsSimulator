# Planning archive

These 14 files are the original pre-implementation planning bundle: requirements Q&A, a Fyers
feasibility report, a broker comparison, and step-by-step build instructions written before any
code existed. They're superseded by the actual implementation and by `docs/ARCHITECTURE.md` /
`docs/STRATEGIES.md` / `docs/SETUP.md`, but kept here for historical context — e.g. the original
reasoning for design decisions, or the full Fyers API capability analysis in
`FYERS_FEASIBILITY_REPORT.md`.

Nothing in here reflects the current, as-built system. Don't treat it as a source of truth.
