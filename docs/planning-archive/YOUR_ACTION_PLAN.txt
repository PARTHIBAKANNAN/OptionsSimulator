─────────────────────────────────────────────────────────────────────────────

1. Open Terminal (or PowerShell on Windows)

2. Go to your project folder:

3. Create file: download_nifty_data.py
   
   Copy this code:
   ─────────────────────────────────────────────────────────────────────────
   import pandas as pd
   from datetime import datetime, timedelta
   import os
   from dotenv import load_dotenv
   from fyers_apiv3 import fyersModel

   load_dotenv()

   app_id = os.getenv("FYERS_APP_ID")
   app_secret = os.getenv("FYERS_APP_SECRET")
   access_token = os.getenv("FYERS_ACCESS_TOKEN")

   fyers = fyersModel.FyersClient()
   fyers.app_id = app_id
   fyers.app_secret = app_secret
   fyers.access_token = access_token

   end_date = datetime.now()
   start_date = end_date - timedelta(days=90)

   data = {
       "symbol": "NSE:NIFTY50-INDEX",
       "resolution": "1",
       "date_format": "1",
       "range_from": int(start_date.timestamp()),
       "range_to": int(end_date.timestamp()),
       "cont_flag": "1"
   }

   print("🔄 Downloading NIFTY data from Fyers...")
   response = fyers.history(data)

   if response.get("status") == "ok":
       candles = response["candles"]
       print(f"✅ Got {len(candles)} candles")
       
       df = pd.DataFrame(candles, columns=["Timestamp", "Open", "High", "Low", "Close", "Volume"])
       df["Timestamp"] = pd.to_datetime(df["Timestamp"], unit='s')
       df["Timestamp"] = df["Timestamp"].dt.strftime("%Y-%m-%d %H:%M:%S")
       df = df[["Timestamp", "Open", "High", "Low", "Close", "Volume"]]
       
       os.makedirs("data/historical", exist_ok=True)
       df.to_csv("data/historical/nifty_90days.csv", index=False)
       print(f"💾 Saved to: data/historical/nifty_90days.csv")
       print(f"   Rows: {len(df)}")
   else:
       print(f"❌ Error: {response}")
   ─────────────────────────────────────────────────────────────────────────

TROUBLESHOOTING:
================================================================================

Q: Where do I find FYERS_ACCESS_TOKEN?
A: Go to https://myapi.fyers.in/ → Click on your app → Copy the access token
   (or generate new token if expired)

Q: I don't see an "Export" button in Fyers web?
A: Use the Python script method instead - it's more reliable

Q: File has wrong format or too few rows?
A: Check:
   - Did you select 1-minute timeframe? (not 5-min or 15-min)
   - Did you select NSE:NIFTY50-INDEX? (not NIFTY stocks)
   - Is the date range 90 days? (should have ~35,000 rows)

Q: When I run the Python script, I get "No module named fyers_apiv3"?
A: Run: pip install fyers-api
